KEYBOARD SHORTCUTS

Files and figures
  Ctrl+Enter     Run
  Ctrl+S         Save plot
  Ctrl+E         Open the Export data dialog
  Ctrl+Shift+C   Copy figure to clipboard
  F5             Rescan the input folder
  Enter (input)  Rescan, and remember that folder

Editing
  Ctrl+Z         Undo
  Ctrl+Y         Redo  (also Ctrl+Shift+Z)

Session tabs
  Ctrl+T         New tab (blank session)
  Ctrl+W         Close the current tab
  Ctrl+Tab       Next tab  (Ctrl+Shift+Tab = previous)

Plot, with the mouse
  Click curve      Select it
  Dbl-click        Solo that curve (again = restore)
  Click legend     Hide / show that trace
  R-click curve    Quick actions
  Drag a box       Zoom into it (2D)
  Mouse wheel      Zoom (2D about the cursor; 3D camera)
  Dbl-click pill   Reset that pane divider

  The quick actions are inspect, solo, hide, toggle decompression
  (D), defringe compare, show in data table and deselect.

Plot, with the keyboard
  Arrow keys     Pan the 2D view / orbit the 3D camera
  + / -          Zoom (2D about center; 3D camera)
  0              Fit the 2D view / reset the 3D camera
  1 / 2 / 3 / 4  Stacked & 3D: off / 2D stacked / 3D ridge / 3D shape
  [  /  ]        Previous / next colormap
  Ctrl+R         Reset 3D view

Data
  Ctrl+D           Toggle the raw data table
  Ctrl+C (table)   Copy the selected rows

Fringe workbench
  PgUp / PgDn    Previous / next pressure point
  F11            Fill the screen in the pop-out (Esc leaves it)

Elsewhere
  Drop a folder  Make it the input folder and rescan (Windows)
  F1             This shortcuts list
  Esc            Close the dialog on top
  Esc (running)  Cancel the run

Single keys (numbers, brackets, arrows, + / - and 0) do nothing
while you type in a box. Esc also cancels a pane-divider drag.
